# Repo Instructions

This repository is a Jekyll site powered by `jekyll-theme-chirpy`.

## What to know first

- Blog posts live in `_posts/`.
- Monthly roundup content lives in `_ms_tech_news/`, `_ms_release_radar/`, and `_wiz_release_radar/`.
- Pages and navigation tabs live in `_tabs/`.
- Shared templates and layout logic live in `_layouts/` and `_includes/`.
- Local run/test helpers live in `tools/run.sh` and `tools/test.sh`.

## Working rules

- Keep changes small and consistent with the Chirpy theme.
- Prefer editing content in Markdown/front matter over touching theme internals.
- Use `tools/test.sh` to validate site output when changing templates, config, or shared includes.
- Avoid committing generated site output or caches.
