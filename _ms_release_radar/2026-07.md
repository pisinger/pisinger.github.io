## Security Architect Observations

- **Multi-cloud security coverage expansion**: Over 200 new AWS and GCP recommendations now affect Secure Score, requiring security architects to review and prioritize findings across heterogeneous cloud environments. The expanded coverage includes data, identity, networking, compute, and container categories across ~90 resource types.

- **AI/agent security emerging as critical domain**: Microsoft Defender XDR now assesses AI agent posture risk and provides real-time protection for Agent 365 tooling servers. Security architects must establish governance frameworks for AI agent deployment, access controls, and runtime monitoring.

- **Container security maturity accelerating**: GA of container-level KSPM, Kubernetes misconfiguration enforcement, and serverless container posture management provides comprehensive visibility but requires architecture review of admission control policies and enforcement mechanisms across AKS, EKS, and GKE.

- **Supply chain security hardening**: npm v12 breaking changes, publish-time malware scanning, and Dependabot cooldown defaults represent significant shifts in supply chain risk posture. Architecture reviews should validate CI/CD pipeline compatibility and establish exception processes.

- **Deprecation migration complexity**: Multiple overlapping deprecations (legacy grouped recommendations, five Defender plans, Azure Diagnostics extension, Container Insights legacy auth) require coordinated migration planning to avoid capability gaps and compliance exposure.

- **Zero Trust alignment**: Token-type-specific credential revocation, managed sandbox policy enforcement in GitHub Copilot, and Controlled Configuration for Defender antivirus settings strengthen Zero Trust posture but require identity and access management process updates.

---

## Security Operations Observations

- **Alert tuning required for Ubuntu kernel CVE reclassifications**: AKS-2026-0005 bulletin indicates massive increase in CVE findings from Canonical reclassifications. SOC teams should suppress alerts for CVEs marked "Vulnerable, fix deferred" or "Needs evaluation" until upstream fixes available.

- **New detection capabilities require playbook updates**: SQL data exfiltration alert ("abnormally large number of rows extracted"), AI agent runtime protection alerts, and prompt injection detection in Defender for Office 365 require new incident response playbooks and analyst training.

- **Malware scanning delays impact CI/CD**: npm publish-time scanning introduces 5-15 minute delays. Operations teams should update pipeline timeout configurations and communicate expected latency to development teams.

- **Credential revocation granularity improves incident response**: Token-type-specific revocation enables targeted containment during security incidents. SOC playbooks should be updated to leverage granular deauthorization capabilities.

- **Mitigated alert dismissal reduces noise**: New "Mitigated" dismissal reason for code scanning alerts allows proper tracking of vulnerabilities addressed by compensating controls (WAF, network policies), reducing false positive burden on analysts.

- **OT/IT convergence visibility**: New OT data connectors (Armis, Dragos, Forescout) in Exposure Management provide unified IT/OT vulnerability view but require SOC analyst training on OT-specific risk factors and remediation constraints.
