## Security Architect Observations

- **AKS Ubuntu 22.04 kernel CVE surge requires architectural response**: The Canonical reclassification of hundreds of kernel CVEs means vulnerability scanners will show inflated findings. Architectures should implement the recommended verification workflow (check `linux-azure` package version against Ubuntu CVE Tracker) and establish a process to distinguish AKS-patched vs. genuinely unfixed CVEs. This may affect compliance reporting and audit interpretations.
- **Defender plan consolidation simplifies multicloud posture**: The deprecation of five legacy Defender plans (AKS, ACR, Key Vault, DNS, ARM) and the GA of unified container security capabilities signal a consolidation toward Defender for Containers and Defender for Servers. Multi-cloud architectures benefit from the new EKS/GKE vulnerability assessment parity with AKS.
- **AI agent security becomes a first-class concern**: Microsoft Defender XDR now assesses AI agent posture risk, and Defender for Endpoint provides AI agent runtime protection. Security architectures must account for AI agent discovery, posture assessment, and runtime monitoring as new attack surfaces.
- **GitHub supply chain security deepens with multiple defense layers**: npm v12 install-time security defaults, publish-time malware scanning, Dependabot 3-day cooldown, and OpenSSF malicious-package ingestion create defense-in-depth for the software supply chain. Architectures should evaluate the impact of npm v12 breaking changes on CI/CD pipelines.
- **Azure Monitor legacy agent retirement requires migration planning**: WAD/LAD retirement (completed March 2026), Container Insights legacy auth (Sep 30, 2026), and VM Insights Map/Dependency Agent (June 30, 2028) require coordinated migration to Azure Monitor Agent and managed identity authentication.

- **SOC must update Advanced Hunting queries for Entra ID sign-in tables**: The deprecation of `AADSignInEventsBeta` and `AADSpnSignInEventsBeta` by October 19, 2026 requires updating all custom detections, hunting queries, and workbooks that reference these tables. While auto-migration is promised, validate all custom content post-migration.
- **New SQL VA individual recommendations will affect Cloud Score and alert volume**: The transition from grouped to individual SQL VA recommendations (26+ rules at database level) will increase the number of discrete findings. SOC should review baseline and exemption workflows to manage alert noise.
- **GitHub Actions malicious workflow hold protection reduces CI/CD risk**: Public repository workflows identified as potentially malicious are now held for approval. SOC should monitor for held workflow notifications and establish review procedures.
- **Prompt injection protection in Defender for Office 365 adds new detection category**: SOC should review prompt injection detection alerts, tune as needed, and incorporate into phishing investigation playbooks.
- **Insider Risk Management unified alert experience consolidates triage**: The merged Triage Agent and Standard alert dashboards simplify IRM workflows. SOC should review the new unified interface and update standard operating procedures accordingly.
