# Microsoft Security Release Radar - July 2026

## ⛵ AKS

| Indicator | Feature | Type | Priority | Description |
|---|---|---|---|---|
| 🔴 | AKS-2026-0005 Ubuntu 22.04 kernel CVE reclassification | Security | High | Canonical reclassified many historical kernel CVEs from Needs evaluation to Vulnerable, increasing scanner findings. Verify the installed `linux-azure` version in the Ubuntu CVE Tracker; upgrading AKS alone may not clear unfixed upstream findings. |
| 🔴 | Istio security fixes for ISTIO-SECURITY-2026-005 | Security | High | Istio add-on revisions `asm-1-28`, `asm-1-29`, and `asm-1-30` include the fix. Restart Istio workload pods so newer `istio-proxy` images are injected. |
| 🔴 | containerd security fixes | Security | High | containerd moved from 1.7.32 to 1.7.33, including fixes for CVE-2026-53488, CVE-2026-47262, and CVE-2026-34986. |
| 🟢 | Artifact Streaming | GA | Medium | Container image streaming from Azure Container Registry is generally available, reducing initial pod startup time by pulling only required layers. |
| 🟢 | Secure TLS bootstrapping | GA | Medium | Secure TLS bootstrapping is enabled by default in West Central US and East Asia. |
| 🟢 | GPU Secure Boot and existing-pool Trusted Launch | GA | Medium | Secure Boot is supported for GPUs with Azure Linux, and Trusted Launch can be toggled on existing Linux node pools. |
| 🟡 | Node Disruption Policy | Preview | Medium | Public preview lets operators define windows during which reimage-triggering operations may occur. |
| 🟡 | Automatic zone placement, Prepared Image Specification, and full-cache Ephemeral OS disks | Preview | Low | These previews improve zone selection, node readiness, and resilience when remote OS storage is unavailable. |
| ⚫ | `enableCustomCATrust` preview property | Deprecation | High | The property retires September 14, 2026; remove it and use `--disable-custom-ca-trust` to avoid scaling and certificate-update failures. |
| ⚫ | Kubernetes 1.30 and unsupported node-pool creation paths | Deprecation | High | Kubernetes 1.30 is deprecated; AKS also no longer creates Windows Server Annual Channel or Flatcar node pools. Migrate affected workloads and use supported versions. |
| 🔵 | AKS behavioral and component updates | New/Updated | Medium | AKS fixed API Server Authorized IP enforcement, unsafe legacy Container Insights authentication, and Cilium anti-spoofing behavior, and updated Cilium, CSI, CoreDNS, autoscaler, and OS images. |

## Security Architect Observations

- Standardize vulnerability triage around exact package identity and upstream status: AKS Ubuntu findings require `linux-azure` verification rather than assuming a Kubernetes or node-image upgrade resolves them.
- Treat agent identity, runtime inspection, MCP controls, prompt-injection detection, and network DLP as a new defense-in-depth boundary; define ownership and telemetry retention before broad enablement.
- Rework cloud-security governance for the shift from grouped to individual recommendations, including API schemas, exemptions, score interpretation, and multicloud resource coverage.
- Plan identity and privilege migrations for Unified RBAC, temporary Purview roles, Intune zero-touch permissions, and token-type credential revocation; validate least-privilege mappings in staging.
- Review deprecation exposure in Azure Monitor, AKS, Defender plans, Purview Azure SQL protection, and npm/GitHub automation as architecture dependencies rather than isolated product changes.

## Security Operations Observations

- Add AKS Istio/containerd CVEs and MDVM accuracy corrections to patch-verification runbooks, including pod restart checks and scanner false-positive handling.
- Enable and tune Dependabot malware alerts, CodeQL custom configuration, npm publish/install monitoring, and GitHub Actions approval events in the SOC and CI/CD response workflows.
- Update Sentinel detection-as-code pipelines to validate BICEP changes, review permissions, and safely promote repository-backed custom detections.
- Monitor new AI-agent posture, Agent 365, MCP, prompt-injection, and Purview DLP signals for alert volume, missing telemetry, and false-positive trends.
- Rebaseline Defender Cloud reporting and automation against individual recommendations, Cloud Score versus Secure Score, and expanded AWS/GCP coverage.
