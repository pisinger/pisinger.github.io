Rust - The rust/hard-coded-cryptographic-value query now treats arithmetic, bitwise, and string append operations as barriers. ## Security Architect Observations

- **AI Agent Security Emergence**: Multiple products (Defender XDR, Defender Endpoint, Purview) now offer AI agent posture assessment, runtime protection, and prompt injection detection. Architects should establish AI agent governance frameworks covering agent registration, risk assessment, and monitoring integration with existing SIEM/SOAR platforms.

- **Multicloud Security Posture Expansion**: Defender for Cloud's 200+ new AWS/GCP recommendations and serverless container coverage significantly expand CSPM scope. Architects should reassess multicloud security baselines and integrate new recommendation categories into cloud security governance.

- **Supply Chain Security Hardening**: GitHub's npm v12 breaking changes (install-time security defaults, 2FA-bypass deprecation, publish-time malware scanning) require CI/CD pipeline updates. Architecture teams should audit automation relying on legacy npm behaviors and plan migration to authenticated publishing workflows.

- **Container Security Maturation**: AKS artifact streaming GA, Kubernetes misconfiguration enforcement, and serverless container posture capabilities provide defense-in-depth for containerized workloads. Architects should evaluate admission-time enforcement policies and integrate container-level KSPM recommendations into DevSecOps pipelines.

- **Network Segmentation Evolution**: Fabric's workspace outbound access protection and Azure Monitor's retirement of direct Event Hubs/Storage uploads signal shift toward centralized egress control architectures. Network architects should plan migration to data connection rule-based governance models.

- **Identity-Centric Security Expansion**: Defender Identity's SaaS password protection integration (Salesforce, ServiceNow via Cloud Apps) and Intune's Controlled Configuration for Defender settings extend identity security perimeter. Architects should map identity attack surface across hybrid SaaS/on-premises environments.
