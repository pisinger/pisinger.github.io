## Security Architect Observations

- **Defense-in-depth for AI agents:** The convergence of Defender XDR, Defender for Endpoint, and Defender for Office 365 around AI agent protection signals a new attack surface requiring updated architecture reviews for agent deployments, permissions, and runtime monitoring.
- **Container security posture expansion:** Defender for Cloud's GA of container-level KSPM, Kubernetes misconfiguration enforcement, and serverless container discovery requires architects to reassess admission control, CI/CD integration, and multi-cloud container governance models.
- **AKS deprecation velocity:** Multiple AKS deprecations (Kubernetes 1.30, Custom CA Trust preview, Windows Annual Channel, Flatcar) create a compatibility risk window; architects should inventory affected clusters and build migration runbooks.
- **GitHub supply chain hardening:** npm v12 install-time security defaults, publish-time malware scanning, and Dependabot cooldowns collectively reduce supply chain risk but may break existing CI/CD pipelines relying on automatic script execution or immediate package availability.
- **Observability pipeline migrations:** Retirement of the Azure Diagnostics extension and legacy Container Insights authentication requires migration to Azure Monitor Agent and managed identity, which impacts data routing, network rules, and compliance retention architectures.

## Security Operations Observations

- **AKS CVE scanner noise:** The Canonical Ubuntu kernel CVE reclassification will significantly increase vulnerability scanner findings on AKS Ubuntu 22.04 nodes; SOC teams should tune scanners to check `linux-azure` package versions in the Ubuntu CVE Tracker rather than generic `linux` mappings to avoid false positive fatigue.
- **MDE Linux deployment visibility:** The new Defender Deployment Tool for Linux and its Device Timeline integration improve fleet-wide deployment monitoring; SOC teams should update Advanced Hunting queries to capture deployment stage, status, and failure reasons.
- **Istio workload restarts required:** AKS Istio add-on security fixes for ISTIO-SECURITY-2026-005 require pod restarts to trigger proxy re-injection; operations teams should plan rolling restarts for affected workloads and validate mTLS posture after restart.
- **Defender Identity v3.x migration readiness:** Automatic RPC auditing and migration readiness tooltips reduce manual overhead, but operations teams should still validate domain controller prerequisites and monitor sensor health during phased v2.x to v3.x migrations.
- **GitHub Actions workflow approvals:** The new automatic hold for potentially malicious workflows in public repositories may delay CI/CD runs; operations teams should ensure adequate write-access coverage for approval workflows and monitor for accidental denials.
