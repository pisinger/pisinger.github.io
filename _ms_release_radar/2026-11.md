# Microsoft Security Release Radar - November 2026

## Security Architect Observations

- **AKS CVE exposure spans four layers.** The Brotli and Linux kernel advisories cannot be closed by node image updates alone: containers, customer-managed proxies, and add-on images each carry their own patch path, so image provenance and rebuild pipelines become the control of record.
- **Scanner fidelity is now a governance problem, not just a tooling problem.** The OpenSSL EOL bulletin shows upstream-version-only scanners will keep raising findings that Azure Linux has already backported; distribution-aware matching and time-bound, digest-scoped exceptions need to be written into vulnerability management policy.
- **AI agent traffic is becoming a first-class enforcement point.** Azure AI Gateway, the Agent 365 integration, Foundry egress controls, and Logic Apps VNet integration collectively create a chokepoint model for agent-to-tool traffic; architecture should place identity, egress filtering, and Purview/Defender inspection at the gateway rather than per-agent.
- **Developer-identity attack paths now cross product boundaries.** Device code phishing against Copilot CLI is addressed jointly by the Defender XDR security-for-AI preview and the Defender Cloud Apps GitHub connector; Enterprise-level GitHub onboarding is the architecture prerequisite for that coverage.
- **Control-plane consolidation is underway.** The new Defender portal navigation and the Sentinel-in-Defender consolidation change where detection, automation, and workbook content live; RBAC scopes, saved queries, and runbook links must be re-validated against the new paths.
- **Deprecation and lifecycle debt is accumulating quietly.** Intune's macOS settings entry is classified as a deprecation, macOS 11–13 support has ended for MDE, GitHub will pause Dependabot on inactive repositories, and the Dependabot dismissal window changed; baseline and exception records should reflect these dates.


## Security Operations Observations

- **Hunting coverage broadens but requires query updates.** New `IdentityDirectoryEvents`, `IdentityQueryEvents`, and `IdentityLogonEvents` AD telemetry plus the `SyntheticMediaDetectionEvents` table add detection surface; existing analytic rules and saved hunts should be reviewed for new fields and for overlap with current detections.
- **Deepfake and trusted-identity detections raise triage ambiguity.** Synthetic media events in Teams and device code phishing alerts against Copilot CLI will need SOC playbooks that distinguish impersonation attempts from legitimate executive and developer activity.
- **Secret detection moves into the developer loop.** Opt-in secret scanning inside Copilot reviews and Actions workflow log scanning shift some secret findings left; SOCs should agree with engineering on who owns Copilot-surfaced secrets versus repository alerts, and note the preview's lack of notifications.
- **Alert volume will rise unevenly.** AI Scan bulk enrollment and new secret detectors (Cloudflare, SpaceX) plus tightened filters on major cloud providers will change both false-positive and false-negative baselines; tune before scaling bulk scans.
- **Dependabot behavior changes affect SLA metrics.** The one-year dismissal window and the December pause on inactive repositories can silently alter mean-time-to-remediate reporting; exclude archived alerts from dashboards or annotate them.
- **Automation dependencies need retesting.** Decision actions, managed connectors, and VNet integration in Logic Apps, plus the new Defender navigation paths, can break SOAR playbook links, connector auth, and automation runbook references.
