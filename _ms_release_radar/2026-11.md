## Security Architect Observations

- The AKS Brotli advisory reinforces that node OS patching is insufficient: container images, including customer-managed proxies, must be rebuilt because node image upgrades do not change packages inside workloads.
- AKS-managed add-on images create a shared-responsibility gray zone; scanners that match only upstream OpenSSL versions generate EOL findings that require SBOM- and revision-aware exception handling rather than image modification.
- The `pull_request_target` default block is a high-impact supply-chain control change for public repositories and should be modeled as a platform policy change, with explicit, narrowly scoped workflow allowlists.
- Short-lived GitHub Desktop tokens and the new repository protection context in risk assessments improve credential and coverage governance, but GHES exclusions mean hybrid estates retain asymmetric posture.
- Copilot Studio agent accounts, scoped credentials, MCP access, and A2A delegation expand the non-human identity footprint; permission scoping and lifecycle governance should be defined before broad agent adoption.
- Defender for Endpoint Linux builds expire after nine months, so version currency should be tracked as a configuration compliance control, not only as a patching task.

## Security Operations Observations

- Prioritize detection and verification of unpatched AKS Linux nodes for CVE-2026-98432 and CVE-2026-99999, and confirm workload image rebuilds for CVE-2026-111497 rather than relying on node image status alone.
- Expect GitHub Actions brownout failures on November 9 and 16, 2026; pre-stage alerting on blocked `pull_request_target` runs and suppress expected workflow-failure noise during the windows.
- Tune vulnerability scanners to use distribution-aware matching and OVAL data for Azure Linux add-on images to reduce false positives from OpenSSL EOL-only findings.
- Add Defender for Endpoint Linux 101.26101.0000 and macOS 101.26092.0012 to endpoint compliance reporting and validate sensor health after rollout.
- Incorporate CodeQL 2.27.4 and 2.27.3 accuracy changes into code-scanning baselines to avoid misclassifying reduced false positives as new detection gaps.
- Review Copilot Studio cost and usage telemetry, plus agent invocation logs, to detect anomalous credit consumption or delegated agent activity.
