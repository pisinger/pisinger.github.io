## Security Architect Observations

- **Multicloud coverage expansion is significant**: Over 200 new AWS/GCP recommendations now affect Secure Score, spanning ~90 new resource types. Architects should reassess multicloud posture coverage and ensure Defender for Cloud is enabled across all cloud environments.
- **npm supply chain hardening**: npm v12's opt-in dependency lifecycle scripts and the 3-day Dependabot cooldown represent a defense-in-depth shift. Architects should plan migration to npm v12 and review the `allowScripts` allowlist process for CI/CD pipelines.
- **macOS endpoint deprecation**: macOS 11-13 end of support for Defender for Endpoint creates compliance risk for any remaining Big Sur/Monterey/Ventura systems. Inventory and upgrade planning is required.
- **GitHub innersource advisories enable internal vulnerability management**: GA release of innersource security advisories allows enterprises to manage internal component vulnerabilities with Dependabot-driven remediation — a key capability for private package ecosystems.
- **SQL VA individual recommendations transition**: The move from grouped to individual SQL VA recommendations changes how compliance data is consumed via API and Azure Resource Graph. Update monitoring and reporting tooling accordingly.

## Security Operations Observations

- **New SQL data exfiltration alert in preview**: SOC teams should test the "abnormally large row extraction" alert for SQL servers and tune thresholds before GA to manage false positive risk.
- **GitHub Actions malicious workflow holds**: Potentially malicious workflow runs on public repos are now auto-held for approval. SOC teams should establish a review process for held workflows and monitor approval patterns.
- **Dependabot malware alerts expanded**: With OpenSSF malicious-packages data now ingested, Dependabot malware alerts cover more ecosystems. SOC teams should enable malware alerting if not already active and triage new alert types.
- **Secret scanning webhook now includes `secret_category` field**: The new field distinguishes default vs. generic/AI-detected secrets. Update SOAR playbooks and SIEM ingestion to leverage this field for prioritization.
- **GitHub Copilot security review in preview**: The `/security-review` command provides on-demand scanning. SOC teams should evaluate whether to recommend this for developer workflows as a complementary control to existing SAST/SCA tooling.
