## Security Architect Observations

- **Defender for SQL API retirement** (Aug 16, 2027) requires a migration plan for Vulnerability Assessment and Advanced Threat Protection automation; inventory all dependent scripts and APIs now to avoid a hard cutover.
- **CVE details consumption change** in Azure Resource Graph is a breaking data-model change; security analytics and reporting pipelines that parse CVE properties from vulnerability assessment records must be re-pointed to the new resource type.
- **CIEM overprovisioned identity assessments** for AWS/GCP no longer include unused actions; architects should rely on native cloud provider IAM usage signals and adjust any automated least-privilege workflows.
- **AKS security posture improvements** (Istio Gateway API `automountServiceAccountToken=false`, Entra ID SSH rejection on AzureContainerLinux, engine signature verification on Linux) strengthen default hardening but require validation against existing workloads and Azure Policy guardrails.
- **Unified RBAC default enablement** for new Defender for Cloud Apps customers centralizes role management; existing tenants should plan a deliberate rollout to avoid permission drift across Defender products.
- **GitHub Code Quality path separation** is a billing/telemetry change; enterprise reporting and governance dashboards keyed on the old actor must be updated to avoid undercounting Code Quality usage.

## Security Operations Observations

- **New UEBA anomaly rules** for Check Point, Fortinet, Zscaler, and AWS GuardDuty add detections for anomalous VPN sign-ins, high-risk web access, and suspicious admin changes; tune baselines to reduce false positives on noisy firewall environments.
- **MDVM inaccuracy fixes** (Gimp, Zoom VDI, Cisco IOS XE, pgAdmin4, Autodesk, Remote Help CVEs) will change vulnerability and recommendation results; SOC should re-baseline exposure dashboards and verify remediation queues.
- **Defender Container Sensor updates** (v0.11.6, v0.10.9, v0.9.66, v0.8.59) include security vulnerability fixes; prioritize sensor upgrades across Helm and Arc-managed clusters to close dependency vulnerabilities.
- **On-demand malware scanning** now supports targeted blob/file/container/file-share scanning; SOC can scope scans to reduce cost and noise instead of full storage-account scans.
- **Code scanning "Mitigated" dismissal reason** enables formal risk-acceptance tracking in GitHub; update alert triage playbooks to use it and align with exception processes.
- **AppNet bug fixes** around certificate rotation and east-west gateway labels reduce mesh disruption risk; monitor mesh health after upgrade to catch residual issues.
