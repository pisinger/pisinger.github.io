## 🏗️ Security Architect Observations

- **SQL API retirement runway is long but real.** The classic Defender for SQL VA/ATP APIs retire August 16, 2027; inventory all dependent scripts, automations, and reporting layers and plan a staged migration to the supported configuration model well before the deadline.
- **CVE data consumption shift impacts automation.** Moving detailed CVE properties to the `microsoft.security/cvedetails` resource in Azure Resource Graph changes query contracts; audit and rewrite existing vulnerability-detail queries or risk silently losing detail.
- **AKS security posture is tightening.** Node reimages triggered by SSH/IMDS/outbound/managed-identity changes plus Istio Gateway API `automountServiceAccountToken=false` and Entra SSH rejection on ACL nodes require architecture review of Node Disruption Policy and pod identity handling.
- **MDVM detection accuracy is maturing** with corrections across Gimp, Zoom, Cisco IOS XE, Autodesk, and pgAdmin4 CVEs and new software coverage; revisit vulnerability prioritization as detection quality improves.
- **GitHub supply-chain and license data quality improves**, with registry-sourced licenses and customizable Dependabot branch naming, reducing SBOM and compliance noise and easing CI integration.
- **Cross-tenant DLP semantics** now follow the initiating tenant for Teams conversations, which changes compliance expectations for co-tenant environments and should be reflected in policy design.

## 🧭 Security Operations Observations

- **CVE query contract change (ARG)** is the highest-priority SOC/automation item; update dashboards, notebooks, and workflows that read CVE detail so detection coverage does not regress.
- **AWS/GCP CIEM change** removes the Unused actions list from overprovisioned identity recommendations; redirect permission-usage validation to native AWS IAM last-accessed and GCP IAM insights.
- **New UEBA data sources** in Sentinel (Fortinet, Check Point, Zscaler, GuardDuty) plus on-behavior anomaly insights expand early-warning capability; tune anomaly rules mapped to VPN sign-ins, admin changes, and high-risk web categories to control false positives.
- **Defender for Endpoint Linux audit modes and tamper-protection audit** provide detection-only visibility; plan a phased enablement from audit to enforcement on sensitive Linux workloads.
- **Defender Container Sensor updates** fix pod inventory reliability on Kubernetes pod deletion events; track sensor versions (v0.8–v0.11) and update across fleets to maintain accurate inventory and alerting.
- **Purview auto-labeling simulation and Insights** let IRM/DLP teams validate policy behavior before enforcement, reducing label misclassification risk and false-positive-driven alerts.
- **GitHub Copilot hook-approval security fix** (v1.1.12) closes a skipped-tool-approval gap; ensure users update to the latest Copilot app to avoid bypassed explicit-approval prompts.
