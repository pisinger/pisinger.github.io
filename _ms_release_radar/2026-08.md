## Security Architect Observations

- CVE data model changes in Defender for Cloud (`cvedetails` resource type) and the SQL API retirement signal a broader shift toward consolidated vulnerability consumption; downstream SIEM/AR workflows and custom dashboards should be revalidated for schema and endpoint drift.
- Entra ID's MemberOf deprecation and `User.ReadBasic.All` scope tightening both reduce long-term identity risk but require migration; dynamic group/AU designs built on MemberOf can silently stop updating after the deadline, creating governance gaps if unaddressed.
- Defender security posture is moving toward keyless/managed-identity auth (MDASH Microsoft Foundry, Entra Resource Accounts, AKS workload identity for Azure Files); prioritize phasing out stored secrets and service principal credentials.
- AKS behavior changes (node reimages triggered by SSH/IMDS/outbound/managed-identity changes, automatic zonal placement) increase the need for Node Disruption Policies and maintenance windows to avoid workload impact.
- Unified RBAC default-on for new Defender for Cloud Apps customers plus expanded Security Administrator role rights require a review of least-privilege role assignments and separation of duties across the Defender estate.
- Linux security posture for MDE (engine signature verification by default, AV/tamper audit modes) offers defense-in-depth wins but introduces new telemetry and configuration surfaces to govern.

## Security Operations Observations

- New Sentinel UEBA behaviors/anomalies (FortiGate, Check Point, Zscaler, AWS GuardDuty) expand detection coverage; tune and validate these new rules to avoid alert fatigue and confirm MITRE mapping in SOC workflows.
- MDVM vulnerability-support additions and CVE correction fixes (Gimp, Zoom VDI, Cisco IOS XE, pgAdmin4, etc.) reduce false positives; analysts should refresh exposure dashboards to reflect corrected CVSS scores and recommendations.
- Intune Defender Antivirus audit mode for Linux and MDE Linux audit-mode features create alert-only detections; SOCs should confirm these flow into the Defender portal and adjust triage playbooks for non-blocking findings.
- Defender for Identity automatic auditing for AD CS/AD FS/Entra Connect expands identity-attack surface visibility; ensure connectors and ingestion health are monitored for the new event sources.
- The GitHub Copilot fix for skipped tool-approval prompts is security-relevant to agentic workflows; security teams should verify approval enforcement in developer Copilot configurations.
- Copilot/agent governance additions (Foundry agent enable/disable in Agent 365, Entra MCP Firewall preview) introduce a new monitoring surface for shadow AI/MCP usage; operations should begin inventorying agent and MCP server usage.
