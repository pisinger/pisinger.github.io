# Microsoft Security Release Radar - August 2026

## 🛡️ Microsoft Defender Cloud

| Indicator | Feature | Type | Description |
|---|---|---|---|
| 🔵 | Update to CVE details data consumption in Azure Resource Graph | Update | CVE information is now consumed through the `microsoft.security/cvedetails` resource type to improve query performance and scalability. Existing queries should be updated to use the new resource type. |
| ⚫ | Classic Defender for SQL APIs retirement | Deprecation | Classic Defender for SQL APIs for Vulnerability Assessment and Advanced Threat Protection will be retired on August 16, 2027. Migrate to the supported configuration model before the retirement date. |
| 🟢 | On-demand malware scanning for specific blobs and files | GA | On-demand malware scanning now supports targeted scanning of specific blobs, files, containers, or file shares instead of entire storage accounts. Use filters in the REST API to specify which items to scan. |

Use native cloud provider tools (IAM access activity in AWS, Cloud Asset Inventory in GCP) to validate permission usage. |

## Security Architect Observations

- **Multi-cloud security coverage expansion**: Over 200 new multicloud security recommendations for AWS and GCP resources significantly expand visibility into cross-cloud security posture, affecting Secure Score calculations and requiring review of cloud-agnostic security policies.

- **npm supply chain security hardening**: npm v12 install-time security defaults (allowScripts off, --allow-git none, --allow-remote none) and 2FA-bypass GAT deprecation represent major shifts in package management security posture, requiring automation updates and workflow changes for development teams.

- **Innersource security advisories GA**: Enterprise-internal security advisory publishing capability enables coordinated vulnerability disclosure within enterprise boundaries, improving internal security coordination but requiring governance processes for advisory publication and remediation tracking.

- **AKS node lifecycle management improvements**: Node pool rollback GA and control-plane only LTS upgrades enable safer cluster lifecycle management, reducing downtime during upgrade failures and supporting more conservative upgrade strategies for production workloads.

- **Zero-trust endpoint management expansion**: eSIM management capabilities for corporate Android devices, separate work profile locks, and DDM for Apple VPP apps advance zero-trust endpoint management, particularly for BYOD and mixed-ownership device environments.

## Security Operations Observations

- **UEBA behavioral anomaly detection expansion**: New data sources for Fortinet FortiGate, Check Point, Zscaler, and AWS GuardDuty in Microsoft Sentinel UEBA expand anomaly detection coverage for firewall, VPN, and web proxy events, requiring SOC analyst training on new alert types and MITRE ATT&CK mappings.

- **Malware detection scope expansion**: npm publish-time malware scanning, Dependabot malware alerts across more ecosystems (npm, PyPI, etc.), and GitHub Actions malicious workflow hold mechanisms add new detection layers but may increase false positive rates during initial tuning periods.

- **Mitigated alert dismissal reason**: New "Mitigated" dismissal reason in code scanning helps distinguish externally-mitigated vulnerabilities from won't-fix decisions, improving risk acceptance tracking but requiring updates to alert triage workflows and exception documentation.

- **Credential revocation granularity improvement**: Token-type-specific bulk deauthorization (PATs, SSH keys, OAuth tokens, GitHub App tokens) enables more targeted incident response, reducing blast radius during credential compromise scenarios but requiring updated incident response playbooks.

- **Intune Linux Defender audit mode**: New audit mode for Linux Defender antivirus policies enables threat landscape visibility before enforcement, supporting phased rollout strategies for Linux endpoint protection without immediate remediation impact.
