## Security Architect Observations

- The Azure Files CSI encryption and workload-identity release creates a clear path to remove storage credentials from AKS workloads and enforce encryption in transit.
- Unified RBAC becoming the default for new Defender Cloud Apps tenants warrants a common role model across Defender workloads and documented separation-of-duties controls.
- Defender Cloud's removal of AWS and GCP unused-action evidence creates a multi-cloud architecture gap that must be filled with provider-native IAM telemetry.
- Purview's connected-app DLP and labeling previews extend governance into Box and Google Workspace, but connector trust, data residency, and policy parity require validation before enforcement.
- npm v12, CodeQL configuration centralization, and license compliance enable stronger supply-chain guardrails but may break builds, custom queries, or repository workflows without staged adoption.
- Intune's Windows 365 for Agents baseline should become the starting control set for agentic Cloud PCs, with deviations handled through formal exceptions.

## Security Operations Observations

- Sentinel's new Fortinet, Check Point, Zscaler, and GuardDuty UEBA signals should be baselined before promotion into high-severity incidents to control false positives.
- MDVM detection corrections can materially change exposure counts; reconcile affected software inventories and reopen remediation tickets where new support now identifies risk.
- The new SQL extraction alert and Sentinel behavior anomalies should be mapped to existing exfiltration playbooks and tested against expected administrative and batch activity.
- GitHub's token-type revocation enables narrower incident containment; update credential-compromise runbooks and verify responders hold the required permissions.
- Code-scanning's Mitigated dismissal reason should require evidence, expiry, and compensating-control ownership so it does not become an unreviewed alert-suppression path.
- Unattended Remote Help and default-enabled Copilot automations increase privileged unattended activity; audit logs and alerting should distinguish approved support or automation from anomalous sessions.
