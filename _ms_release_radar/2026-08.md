## Security Architect Observations

- **Defense-in-depth hardening:** AKS now defaults Istio Gateway API to `automountServiceAccountToken=false`, MDE on Linux enables engine signature verification by default, and Defender Antivirus on Windows is hardened against network credential exposure — align workload manifests and config baselines to these posture improvements.
- **CIEM coverage regression:** Removing unused-actions from AWS/GCP overprovisioned identity assessments means Defender no longer presents permission-usage signals; architects should treat native AWS IAM last-accessed and GCP IAM insights as the authoritative source for least-privilege validation.
- **Data-plane API changes:** The shift of CVE details to the `microsoft.security/cvedetails` resource and the SQL VA API retirement both require governance of downstream queries and automation; audit all consumers before the SQL retirement date.
- **Governance gap closure:** Foundry agents now expose enable/disable controls in Admin Center, and Copilot worktree/commit-attribution controls add agent governance — apply consistent policy across the full agent estate.
- **Multi-cloud/hybrid:** Expanded multicloud recommendations and connectors (Azure DevOps for MDASH, non-Microsoft app DLP) broaden coverage but add review surface; validate Secure Score impact of the 200+ new GA recommendations against planned budgets.
- **Compliance:** Windows 365 for Agents security baseline and expanded AD CS/AD FS/Entra Connect event auditing reduce drift and improve auditability for agentic and identity infrastructure.

## Security Operations Observations

- **Alert tuning:** New Sentinel UEBA anomaly rules and the SQL abnormal-row-extraction alert will generate new signal; baseline user/device histories before tuning to limit noise across Check Point, Fortinet, Zscaler, and GuardDuty data.
- **Detection coverage:** UEBA now maps FortiGate/GuardDuty behaviors to MITRE techniques (T1685, T1070, T1078, T1602) — map to SOAR playbooks and confirm CommonSecurityLog ingestion is enabled for these sources.
- **Monitoring gaps:** Defender Container Sensor v0.11.x/0.10.x/0.9.x ship with pod-inventory reliability and dependency fixes — apply to close container runtime blind spots; verify AKS node-reimage events are captured given new trigger behaviors.
- **SOAR implications:** Offboard-machine API for Linux and Purview priority-cleanup/deletion flows enable automation but raise false-positive and data-loss risk; gate automated offboarding and permanent deletion behind approval workflows.
- **False-positive risk:** DLP policy-tip changes under mandatory labeling and cross-tenant Teams enforcement (initiating-tenant) can shift expectations; validate policy outcomes before broad rollout.
- **Inventory accuracy:** MDVM continues to add product coverage (Azure Storage Explorer, OBS, Windows Terminal, Power BI Report Server, etc.) and fix CVE-scoring inaccuracies — refresh vulnerability dashboards and re-baseline affected CVEs.
