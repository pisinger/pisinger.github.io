## Security Architect Observations

- Identity telemetry is moving from opt-in to default: Defender for Identity will auto-enable sensor v3.x and Windows auditing for existing workspaces, and Defender for Cloud Apps will auto-enable the SaaS accounts integration with Identity inventory. Architecture reviews should validate role exclusions, data-sharing boundaries, and consent assumptions instead of assuming an administrator will act.
- Toolchain and sensor currency is now a security control. The nine-month MDE Linux version expiry, the loss of CodeQL traced extraction on Xcode 27 and macOS 27, and the Intel Mac deprecation all create windows where endpoint or code coverage silently degrades; pin and track versions explicitly.
- Supply-chain controls are converging into policy gates: package firewall, open source license compliance, push attribution, and expanded secret scanning push protection should be designed as layered preventive controls with centralized exceptions and audit trails.
- Defender for Cloud plan management moving into the Defender portal, together with DWU billing, changes infrastructure-as-code and cost-governance workflows; KSPM recommendation rescoping to controllers also shifts Secure Score baselines and should be reflected in posture targets.
- Agentic AI introduces new identity and data boundaries. Agent 365 and API Management MCP governance, Copilot Studio agent accounts with their own credentials, persistent business process memory, and voice biometrics all require Entra agent identities, scoped permissions, and durable audit records as first-class architecture objects.
- Endpoint coverage remains uneven: Microsoft Store application vulnerability assessment is limited to a select set of apps, and Linux security fixes are not always published as separate advisory items, so compensating controls and build-level verification are still required.

## Security Operations Observations

- Twenty-six new Defender for Identity alerts substantially expand Entra ID, Active Directory Certificate Services, Kerberos, and Okta detection coverage. Triage runbooks, entity mappings, and analyst training should be updated for ESC1, ESC8, ESC11, diamond ticket, PKINIT, and Certighost scenarios before enabling broadly.
- MDE Linux releases bundle security fixes without always listing a separate Security Patch item. SOC monitoring should track installed build versions and expiration dates rather than relying solely on advisory feeds.
- New EmailPostDeliveryEvents ApproverUpn data and Teams meeting reporting add investigation context; existing advanced hunting queries, submission triage queues, and remediation audit reports should include these fields.
- Dependabot withdrawn alerts now emit a webhook action and return 410 Gone, so SOAR deduplication and closure logic must distinguish withdrawal from deletion. The pnpm 12 lockfile gap can silently close alerts and should be monitored separately.
- The Sentinel SAP BTP rule introduces a 14-day lookback and a CVSS 7.0 threshold; validate SAP data ingestion, subaccount and space correlation, and threshold tuning to avoid excessive or missed detections.
- KSPM recommendation rescoping and expanded store-app vulnerability coverage will change recommendation and alert volumes; rebaseline dashboards and suppression rules. Anthropic secret push protection may also create developer friction requiring guidance and exception handling.
