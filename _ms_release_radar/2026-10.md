## Security Architect Observations

- Identity control planes are converging on Microsoft-hosted defaults: Defender for Identity sensor v3.x activation and Windows auditing can turn on automatically, and AKS enables platform-managed etcd encryption keys by default on 1.37+. Designs that assumed opt-in behavior need explicit exception and change-control paths.
- Defender for Cloud is consolidating management in the Defender portal with DWU-based billing and controller-scoped KSPM recommendations. Plan cost model, RBAC, and Secure Score baselines before migrating subscriptions.
- Supply chain defense is moving left and into the install path: package firewall, context-aware push protection, reachability analysis, and ruleset-based license compliance all change developer and CI gate design. The package firewall is npm-only in preview, so coverage gaps remain for other ecosystems.
- Deprecated tooling can silently degrade detection: CodeQL traced scans are unavailable on macOS 27/Xcode 27, legacy Device Control v1 is retired on macOS, and Cilium 1.20 drops Kafka-aware policy enforcement. Validate scanner and policy coverage after upgrades.
- Cross-cloud identity exposure is expanding through Defender for Identity Okta coverage and Defender for Cloud multicloud onboarding. Governance must extend to non-Microsoft identity providers and hybrid servers.
- Agentic AI adoption introduces new governance surfaces: Copilot Studio agents appear in Agent 365 with their own credentials, and API Management MCP tool-level controls determine how agent actions are constrained.

## Security Operations Observations

- Defender for Identity adds a large alert set across AD CS abuse (ESC1, ESC8, ESC11), Kerberos ticket attacks, DPAPI and DNS exfiltration, plus Okta and Entra MFA registration anomalies. Expect initial volume and tune entity and threshold rules rather than suppressing whole alert families.
- MDE Linux now emits TCP socket bind telemetry as `ListeningConnectionCreated` in `DeviceNetworkEvents`; update hunting queries and detection content to use the new action type, and account for gradual rollout.
- Office 365 hunting gains the `CallActivityEvents` table and the `ApproverUpn` field in `EmailPostDeliveryEvents`, enabling Teams call investigation and remediation audit trails. Update SOC playbooks and workbooks to consume them.
- MDVM inaccuracy fixes remove multiple CPE misattributions and false positives (for example CVE-2021-44228 on WebLogic and CVE-2017-15097 on PostgreSQL); re-baseline vulnerability dashboards and avoid re-opening previously closed false positives.
- AKS OpenSSL EOL scanner findings require distribution-aware triage; teach analysts to verify image digests, SBOM package revisions, and backport evidence before escalating, and do not modify AKS-managed add-on images.
- Azure Container Apps log migrations can break alerts and workbooks that reference `ContainerAppConsoleLogs_CL` and `ContainerAppSystemLogs_CL`; inventory detections dependent on those tables before cutover.
