# Microsoft Security Release Radar - October 2026

## Security Architect Observations

- Agentic identity is now a first-class architecture concern. Entra agent lifecycle policies, Copilot Studio agent-owned accounts, and API Management's Agent 365 integration all create non-human identities with mailboxes, credentials, and MCP tool reach; inventory and sponsor attestation must extend to them or they become unowned persistence.
- The identity control plane is moving toward phishing-resistant, device-bound credentials. Passkeys as a first MFA method, Windows Hello for Business and macOS Platform SSO as standalone MFA, and Universal CAE with device risk tighten sign-in but require Conditional Access, Authentication Strength, and device compliance policies to be redesigned together.
- Detection coverage is consolidating around AD CS and Kerberos attack paths. Twelve new Defender for Identity alerts target ESC1/ESC8/ESC11, CA key theft, PKINIT, and diamond tickets; certificate authority hardening, template ACL review, and PKINIT monitoring should be treated as a single program rather than separate findings.
- Deprecation debt clusters in November 2026 through February 2027: Kubernetes 1.31/1.34 support, AKS VMAS node pools, ACA Log Analytics destinations, legacy Apple MDM update workloads, Apple Setup Assistant legacy, Microsoft-provided Entra telephony, and the Copilot Studio WhatsApp channel. Each has a hard date and a distinct owning team, so a single migration calendar is warranted.
- Encryption and admission defaults are tightening in AKS: platform-managed keys become default for etcd on 1.37+, AKS Automatic blocks customer mutation of system namespaces, and prepared image specifications now fail closed on missing permissions. Custom admission webhooks and image-bake pipelines must be validated before cluster upgrades.
- Supply chain controls are shifting left into install time. GitHub's package firewall, reachability analysis, license compliance rulesets, and Dependabot API/version metadata let policy be enforced on dependency resolution; build agents and CI runners should be treated as policy-enforced endpoints, not trusted installers.


## Security Operations Observations

- Defender for Identity adds 26 alerts across Entra ID, Active Directory, and Okta in a single month. Expect an initial spike in AD CS and MFA-registration alerts; tune by entity and baseline legitimate certificate enrollment and helpdesk-driven MFA resets before enabling automated response.
- Microsoft-provided SMS and voice delivery retiring February 1, 2027 changes authentication telemetry paths. SOC detections that key on telephony provider behavior or delivery failures need revalidation once third-party providers are configured.
- New hunting surfaces require updated queries and workbooks: `CallActivityEvents` for Teams calls and meetings, `ApproverUpn` in `EmailPostDeliveryEvents`, and `DeviceNetworkEvents` with `ActionType = ListeningConnectionCreated` from Defender for Endpoint on Linux (gradual rollout).
- Reachability verdicts and withdrawn-alert signals change Dependabot triage. Prioritize reachable and potentially reachable alerts, treat unreachable as lower priority, and update SOAR flows to consume the `withdrawn` webhook action and the 410 Gone API response instead of 404.
- KSPM recommendations moving to controller-level scope will change finding counts and Secure Score in Defender for Cloud; suppress or re-baseline dashboards and ticket automations before the shift causes alert volume swings.
- The Azure Container Apps Log Analytics destination deprecation breaks detections built on `ContainerAppConsoleLogs_CL` and `ContainerAppSystemLogs_CL`; audit analytic rules, workbooks, and dashboards before the migration rather than after log flow stops.
