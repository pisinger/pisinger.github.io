## Security Architect Observations

- The month is dominated by lifecycle risk rather than CVEs: Azure Functions runtimes, AKS node images, and Functions on ACA V1 all have hard retirement dates. Treat these as planned migration programs with owners and budget, not ticket-level fixes.
- Identity is converging: Defender XDR's Identity Security dashboard, Defender for Identity's Coverage & Maturity, and automatic sensor v3.x activation broaden identity posture coverage. Automatic workspace creation and Windows auditing enablement should be reviewed against change-control and consent expectations.
- Sentinel's data lake integration with Fabric OneLake, data federation, and custom graphs shifts long-term retention and analytics to a shared data platform; design data-egress, residency, and governance controls before mirroring sensitive tables.
- Platform hardening defaults are tightening (AKS reserved labels, LoadBalancer validation, HTTP proxy/CA size limits, managed namespace prefixes), which can break custom automation and policy-as-code templates if not validated pre-upgrade.
- Defender for Servers billing and server-identification changes, plus the Defender for Cloud grouped-to-individual recommendation transition, affect cost modeling and compliance evidence; reconcile dashboards before the December 14, 2026 deprecation.
- Multi-cloud coverage expands (AWS GuardDuty status, Defender for Cosmos DB and SQL Servers in Azure Government), improving posture consistency across environments but requiring updated connector and licensing governance.

## Security Operations Observations

- Sentinel's Advanced Hunting now unifies Sentinel and Defender XDR data, and data lake tiering changes retention from archive-based to data-lake retention. Update analyst runbooks and tune detection rules against the new retention and query model.
- New identity detections and dashboards (Coverage & Maturity, automatic Windows auditing, sensor v3.x role expansion) will increase identity telemetry volume; pre-tune alert routing to avoid SOC fatigue from newly enabled auditing.
- Memory scanning on Linux (preview) and expanded MDVM third-party library coverage add new detection classes; validate them in a lab to measure false-positive rates before enabling in production.
- GitHub Security changes (stage-only npm tokens, dist-tag OIDC permissions, Dependabot custom runners, agentic autofix with Copilot Memory) alter supply-chain automation; review CI/CD identities and confirm 2FA maintainer approval workflows.
- Intune and Microsoft 365 changes (iOS 18 minimum, Teams call reporting, MDE AI agent runtime protection) change endpoint compliance signals and user-reporting workflows; update SOAR playbooks and compliance policies accordingly.
- No CVE-specific advisories apart from ISTIO-SECURITY-2026-006 appeared in this window; keep monitoring AKS security bulletins for ongoing investigations and non-exploitable CVE assessments.
