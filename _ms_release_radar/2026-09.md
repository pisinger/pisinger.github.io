## Security Architect Observations

- AKS is carrying several concurrent lifecycle transitions: VMAS auto-migration, Windows Server 2022 and Flatcar removal, Azure Linux with OS Guard retirement, and the Windows Server 2025 SKU preview. These require coordinated node pool, image, and upgrade planning before adopting Kubernetes 1.37.
- The Istio add-on security advisory requires both control-plane update and workload pod restart to reinject sidecars; clusters with pinned revisions or custom mesh configurations need explicit validation.
- Defender for Servers billing and server-identification changes can alter protected-server counts and cost allocation; validate Plan 1 and Plan 2 licensing and coverage before November 1, 2026.
- Entra's workload identity and managed-certificate improvements reduce long-lived credential and PKI burden, but require application-owner coordination for SAP SuccessFactors provisioning and TLS inspection cutovers.
- Defender for Identity automatic sensor activation and Windows auditing change the default collection footprint. Organizations should decide on opt-out and validate domain controller coverage, event volume, and workspace design.
- Sentinel data lake plus Fabric mirroring, federation, and graph analytics changes the security data architecture; review data residency, cross-tenant access, and retention governance before broad adoption.

## Security Operations Observations

- Sentinel's integrated data lake onboarding and Advanced Hunting KQL access shift hunting workflows toward historical lake queries and Fabric notebooks; update analyst runbooks and retention expectations.
- Defender for Endpoint expansion to WSL containers and Linux desktops broadens device inventory and alert scope; tune scoping, exclusions, and incident correlation to avoid new noise.
- MDVM's expanded Linux coverage for Node.js, Python, and Java libraries will likely increase vulnerability findings and remediation tickets; prepare triage capacity and ownership routing.
- Defender for Identity sensor v3.x defaults may change which servers report identity signals; confirm alert coverage, duplicate-sensor suppression, and Windows event collection after rollout.
- AKS component updates to Istio, Cilium, Gateway API, and Gatekeeper can change network telemetry and policy enforcement; revalidate detections and admission behavior after upgrade.
- GitHub Copilot App changes around tool permissions, sandboxed shell execution, and default voice dictation affect endpoint governance and data-handling review; update acceptable-use guidance accordingly.
