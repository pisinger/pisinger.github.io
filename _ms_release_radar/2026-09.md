# Microsoft Security Release Radar - September 2026

## ⛵ AKS

| Indicator | Feature | Type | Description |
|---|---|---|---|
| ⚫ | Deprecated Availability Sets (VMAS) auto-migration | Deprecation | Starting September 30, 2026, AKS will automatically migrate deprecated VMAS clusters to Virtual Machines node pools; migrate manually before that date using `az aks update --migrate-vmas-to-vms` to control timing. |
| ⚫ | Azure Linux with OS Guard retirement | Deprecation | Azure Linux with OS Guard (preview) will be retired December 10, 2026; transition to Azure Container Linux by that date or you will no longer receive new node images or security patches, and images are removed March 10, 2027. |
| 🟢 | Kubernetes 1.37 preview and patch versions | GA | Kubernetes 1.37 Preview is rolling out and patch versions `1.36.3`, `1.35.7`, and `1.34.10` are now available. |
| 🟢 | Virtual Machines node pool autoscaling | GA | Autoscaling for Virtual Machines node pools is now generally available, including multi-SKU autoscaling. |
| 🟡 | Managed system node pool conversion | Preview | Existing clusters can now be converted to use a managed system node pool in supported regions after registering the required preview feature. |
| 🟡 | Blue-green to rolling upgrade switch | Preview | Node pools with an in-progress blue-green upgrade can now switch safely to the rolling upgrade strategy. |
| 🟡 | On-Demand Monitor cluster health | Preview | On-Demand Monitor, a new Cluster Health Monitor capability for node health checks and remediation, is available in preview. |
| 🟡 | AKS Hyperscale Configuration | Preview | Lets customers preprovision control plane capacity with H2, H4, H8 profiles for large AI, HPC, and batch workloads. |
| 🔵 | KMS encryption-at-rest validation on 1.37 | New/Updated | AKS returns a validation error when enabling KMS encryption with versioned Key Vault key IDs on 1.37; versionless key IDs are now required. |
| 🔵 | Prometheus namespace-scoped secrets on 1.37 | New/Updated | On Kubernetes 1.37+, ama-metrics uses namespace-scoped access to Kubernetes secrets; configure namespace-scoped secrets access before upgrading if using basicAuth/bearerToken. |
| 🔵 | Managed namespaces reserved prefixes | New/Updated | Managed namespace creation now rejects names beginning with `kube-` or `aks-istio-` to prevent naming conflicts with system-reserved namespaces. |
| 🔵 | HTTP proxy/CCA certificate size limit | New/Updated | New clusters using an HTTP proxy or Custom Certificate Authority now reject CA certificate content larger than 35 KB. |
| 🔵 | Static Egress Gateway LB deregistration | New/Updated | Static Egress Gateway nodes now deregister from the load balancer before node-image upgrade reimages them, reducing interrupted egress traffic risk. |
| 🔵 | Azure Policy validation default | New/Updated | When the Azure Policy add-on is enabled, its Kubernetes-native validation path is now enabled by default across regions. |
| 🔵 | Gatekeeper v3.23.1 | New/Updated | Gatekeeper updated to `v3.23.1`, fixing excessive Validating Admission Policy reconciliation requests. |
| 🔴 | Istio security patches | Security | Istio add-on revisions updated with security patches for ISTIO-SECURITY-2026-006 (`asm-1-29` to v1.29.7, `asm-1-30` to v1.30.4); restart workload pods to reinject the updated `istio-proxy` sidecar. |
| 🔴 | Defender for Containers CSI detach fix | Security | Fixed an issue where the Defender for Containers collector could prevent CSI volumes from detaching, leaving volumes terminating and blocking dependent pods from scheduling. |
| 🔵 | CSI driver updates | New/Updated | Azure File, Azure Disk, and Azure Blob CSI drivers updated across AKS versions for reliability. |
| 🔵 | Cloud Provider Azure, Cilium, App Routing updates | New/Updated | Component images updated for Cloud Provider Azure, Cilium/Hubble/ACNS, and App Routing (ingress-nginx), including new Windows, Azure Linux, Azure Container Linux, and Ubuntu node images. |
| 🔵 | AppNet 1.0-1.2 retired | New/Updated | Retired AppNet versions (Istio 1.25/1.26/1.27) are no longer supported; upgrade to a supported version in self-managed mode. |
| 🟡 | AppNet additional regions | Preview | AppNet is now available in public preview in additional regions including Central US, East US, Japan East, North Europe, West US 2, and more. |
| 🔵 | AppNet component updates | New/Updated | AppNet versions updated to Istio 1.28.10, 1.29.6, and new AppNet 1.5 (Istio 1.30.3); plus multiple mesh, identity, and control-plane bug fixes. |

## Security Architect Observations

- **Runtime/supply-chain end-of-support waves**: Azure Functions retirements (PowerShell 7.4, .NET 8/9, Node.js 22) and the AKS Azure Linux with OS Guard retirement concentrate risk in early 2027; plan stack migrations as security-critical, not cosmetic, because security patches cease after the cutoff dates.
- **Defense-in-depth for untrusted compute**: Azure Container Apps Sandboxes (microVM isolation with suspend/resume) offers a first-class boundary for AI-generated or untrusted code; evaluate as an alternative to custom sandbox infrastructure for CI/CD and multi-tenant agents.
- **AKS platform hardening and deprecations**: VMAS auto-migration plus new default validations (versionless Key Vault keys, certificate size limits, reserved namespace prefixes, Prometheus namespace-scoped secrets) change upgrade prerequisites and require config verification before cluster upgrades.
- **GitHub cryptographic/supply-chain posture**: SSH algorithm removals (SHA-1, Diffie-Hellman) and min 3072-bit RSA plus post-quantum ML-KEM raise key-hygiene and quantum-readiness requirements; the all-platform CodeQL bundle removal forces per-platform CI artifact management.
- **Kubernetes security control plane**: Gatekeeper, Istio (ISTIO-SECURITY-2026-006), Cilium, and CSI component updates plus the Defender for Containers CSI detach fix should be validated across affected clusters, including workload-pod restarts for proxy reinjection.
- **SIEM data architecture shift**: Sentinel data lake + Fabric mirroring/federation changes long-term retention, ingestion, and analytics topology, affecting cost, governance, and multi-cloud data residency planning.

## Security Operations Observations

- **Alert/recommendation churn**: The deprecation of grouped vulnerability assessment and legacy sub-assessments means SOC and GRC workflows must move to individual recommendations, with API, portal, and Azure Resource Graph impact.
- **Detections hardening**: AKS Istio security patches, Defender for Containers volume detach fix, and MDE Linux memory scanning add new detection and protection coverage; monitor for reduced volume-termination and in-memory-threat events.
- **New identity coverage**: Defender Identity sensor v3.x support for AD FS/AD CS/Entra Connect and no-MDE onboarding expands identity telemetry and introduces new sensors to monitor for health and false-positive tuning.
- **GitHub Actions risk surface**: Workflow execution protections GA (with default pull_request_target enforcement Nov 2) and cache-mode least-privilege change pipeline security; use Insights/evaluate mode before enforcement to flag affected runs.
- **Fabric/OneLake monitoring**: New Fabric preview capabilities (capacity operation events, workspace outbound access protection) and Sentinel data lake mirroring introduce new telemetry sources and monitoring surfaces to watch.
- **User reporting and exposure**: Defender Office 365 Teams group-call reporting and MSEM MDASH scan progress add user-reported and exposure-monitoring inputs that may need SOAR routing and alert tuning.
