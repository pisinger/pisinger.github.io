# Microsoft Security Release Radar - September 2026

## 🛡️ Microsoft Defender Cloud

## 🛡️ Microsoft Defender Cloud - Recommendations & Alerts

| Indicator | Feature | Type | Description |
|---|---|---|---|
| ⚫ | Retirement of legacy grouped recommendations (sub-assessments) | Deprecation | Retirement of legacy grouped recommendations has started. Customers can no longer access deprecated data through the API. Azure portal and Azure Resource Graph may take a few days to reflect the change. |
| 🟢 | SQL Vulnerability Assessment transition to individual recommendations | GA | Over 60 SQL Server security recommendations released in GA as part of transitioning Defender for SQL Vulnerability Assessment from grouped recommendations at server level to individual recommendations at scanned database level, including xp_cmdshell restrictions, TLS requirements, auditing settings, and permission hardening. |
| 🟢 | Upgrade Azure Kubernetes Service to remove vulnerabilities from AKS system pods | GA | New security recommendation to upgrade AKS clusters to remove vulnerabilities from system pods. |
| 🟢 | Container images in Docker Hub registry should have vulnerability findings resolved | GA | New security recommendation to resolve vulnerability findings in container images stored in Docker Hub registry. |
| 🟢 | Over 200 new multicloud security recommendations for AWS and GCP | GA | Expanded multicloud security coverage with 200+ new recommendations for AWS and GCP resources across data, identity and access, networking, compute, and container categories affecting ~90 newly supported resource types. |
| 🟢 | Azure Database for PostgreSQL Flexible Servers security recommendations | GA | Ten new security recommendations for PostgreSQL Flexible Servers including audit logging (pgaudit), network security (private endpoints, public IP disabled), backup requirements, and TLS enforcement. |
| 🟡 | An abnormally large number of rows were extracted from your SQL server | Preview | New preview alert for detecting abnormal data exfiltration patterns from SQL servers. |
| 🟢 | Unused API endpoints should be disabled and removed from Function Apps | GA | New security recommendation to disable and remove unused API endpoints in Function Apps. |
| 🟢 | Unused API endpoints should be disabled and removed from Logic Apps | GA | New security recommendation to disable and remove unused API endpoints in Logic Apps. |
| 🟢 | Authentication should be enabled on API endpoints hosted in Function Apps | GA | New security recommendation to enable authentication on API endpoints in Function Apps. |
| 🟢 | Authentication should be enabled on API endpoints hosted in Logic Apps | GA | New security recommendation to enable authentication on API endpoints in Logic Apps. |
| 🟡 | AWS EMR cluster security recommendations (Preview) | Preview | Six new preview recommendations for AWS EMR clusters covering IAM roles, security configuration, network isolation, Kerberos authentication, termination protection, and encrypted logging. |
| 🟡 | AWS Neptune DB security recommendations (Preview) | Preview | Two new preview recommendations for Neptune databases covering deletion protection and public access restrictions. |
| 🟡 | New multicloud preview recommendations for AWS MSK, OpenSearch, GCP App Engine, Certificate Manager | Preview | New preview multicloud recommendations for AWS MSK, AWS OpenSearch Service, GCP App Engine, and GCP Certificate Manager across networking, data, identity and access, and compute categories. |
| 🟡 | AWS data services security recommendations (Preview) | Preview | Over 40 new preview recommendations for AWS data services including AppFlow, Athena, Comprehend, DMS, DataSync, FSx, Kendra, Keyspaces, Kinesis, MQ, and QuickSight covering encryption, backup, access control, and audit requirements. |
| 🟡 | AWS identity and access recommendations (Preview) | Preview | Over 15 new preview recommendations for AWS identity services including Cognito User Pools (MFA, password policies, threat protection), IAM roles (trust policy scoping, wildcard principals), and AppStream WorkSpaces (smart card sign-in, VPC endpoints). |
| 🟡 | AWS compute and container security recommendations (Preview) | Preview | Over 10 new preview recommendations for AWS compute and container services including Auto Scaling Groups (deletion protection, metrics, IMDSv2), CodeBuild (privileged mode, artifact encryption, source authentication), and ECS Fargate (least privilege IAM, read-only filesystem, public exposure). |
| 🟡 | Azure serverless container security recommendations (Preview) | Preview | Six new preview recommendations for Azure Container Apps and Azure Container Instances covering authentication, network exposure, managed identity least privilege, and public access restrictions. |

| Indicator | Feature | Type | Description |
|---|---|---|---|
| 🟡 | AppNet 1.3, 1.4, 1.5 component updates | Preview | AppNet 1.3 updated to Istio 1.28.10, AppNet 1.4 updated to Istio 1.29.6, and AppNet 1.5 (Istio 1.30) now available using Istio 1.30.3. AppNet is in public preview. |
| ⚫ | AppNet 1.0, 1.1, 1.2 retirement | Deprecation | AppNet versions 1.0 (Istio 1.25), 1.1 (Istio 1.26), and 1.2 (Istio 1.27) have been retired and are no longer supported. Self-managed upgrade mode users must upgrade to currently supported versions. |
| 🟡 | AppNet regional availability expansion | Preview | AppNet is now available in public preview in additional Azure regions including Central US, East US, East US 2, Japan East, North Central US, North Europe, South India, Southeast Asia, West Central US, West US 2, and West US 3. |
| 🔵 | AppNet member join validation improvements | New/Updated | AppNet now validates cluster prerequisites at member-join time and returns clear, actionable errors when clusters are missing required add-ons (Microsoft Entra/AAD or Managed Gateway API) or running unsupported AKS Kubernetes versions. |
| 🔵 | AppNet Gateway API CRD conflict resolution | New/Updated | Clusters using AKS managed Gateway API no longer encounter CRD ownership conflicts when joining a mesh; AppNet defers to add-on-provided Gateway API CRDs. |
| 🔵 | AppNet resource move restrictions | New/Updated | Moving AppNet resources across resource groups or subscriptions is now blocked as these move operations are not supported for AppNet. |
| 🔵 | AppNet Managed Control Plane certificate rotation fix | New/Updated | Fixed an issue where the AppNet Managed Control Plane could fail to start after an intermediate certificate authority rotation, which could disrupt the entire mesh. Certificate rotation is now handled reliably. |
| 🔵 | AppNet multicluster east-west gateway network label fix | New/Updated | Fixed an issue where multicluster east-west gateways were missing a required network label, causing cross-cluster traffic to fail. |
| 🔵 | AppNet Microsoft Entra authentication member update fix | New/Updated | Fixed an issue where member clusters using Microsoft Entra (managed identity) authentication were rejected on update, which had blocked member updates and version upgrades. |
| 🔵 | AppNet mesh resource cleanup on member leave | New/Updated | Fixed leftover mesh resources being orphaned on a member cluster after it left the mesh; these are now cleaned up. |
| 🔵 | AppNet member deletion retry loop fix | New/Updated | Fixed member deletion being stuck in a retry loop when the underlying cluster had already been removed; already-deleted resources are now treated as a success. |
| 🔵 | AppNet Managed Control Plane diagnostic logging fix | New/Updated | Fixed an issue where AppNet Managed Control Plane diagnostic logs were missing from customer Log Analytics workspaces. |
| 🔵 | AppNet member join fast-fail validation | New/Updated | Fixed an issue where member join would retry when the cluster had a customer-fixable configuration error; it now fails fast and returns the validation error so it can be corrected. |
| 🔵 | AppNet ApLink and member operation error messaging | New/Updated | Fixed an issue where failed AppLink and member operations returned a generic error instead of the specific reason; actionable failures (such as joining a cluster already connected to another AppLink) now explain what went wrong and how to resolve it. |

## Security Architect Observations

- **Multicloud security posture expansion**: The release of 200+ multicloud security recommendations for AWS and GCP significantly expands Defender for Cloud's native security coverage across hybrid environments, enabling unified security posture management but requiring careful prioritization to avoid alert fatigue during initial deployment.

- **SQL security hardening granularity**: The transition from grouped to individual SQL Vulnerability Assessment recommendations provides finer-grained visibility into database security posture but increases the total number of recommendations to track, requiring updated governance processes.

- **Container security depth**: New recommendations for AKS system pods, Docker Hub vulnerability resolution, and serverless containers (Azure Container Apps/Instances, ECS Fargate) reflect the industry shift toward container-first security strategies and require updated container lifecycle security controls.

- **macOS support modernization**: The deprecation of macOS 11/12/13 support aligns Defender for Endpoint with Apple's current support lifecycle but requires immediate upgrade planning for organizations with legacy macOS deployments.

- **AppNet production readiness**: Multiple bug fixes in AppNet (certificate rotation, CRD conflicts, diagnostic logging, member lifecycle) indicate the service is maturing toward general availability, making it a viable candidate for production service mesh deployments.

---

## Security Operations Observations

- **Data exfiltration detection**: The new preview alert for abnormal SQL server row extraction provides SOC teams with an additional behavioral indicator for data theft detection but requires baseline tuning to minimize false positives in data-intensive environments.

- **Linux memory forensics capability**: Memory scan for Linux enables detection of memory-resident threats that bypass file-based scanning, expanding Linux endpoint visibility but requiring SOC analyst training on memory-based alert investigation.

- **WSL container visibility**: The WSLc plugin support extends Defender for Endpoint telemetry into Windows Subsystem for Linux containers, closing a blind spot for development workloads but increasing the volume of container-related alerts to triage.

- **API security recommendations**: New GA recommendations for API endpoint authentication and cleanup in Function Apps and Logic Apps provide actionable guidance for reducing API attack surface but require coordination with development teams for remediation.

- **PostgreSQL security baseline**: Ten new PostgreSQL Flexible Server recommendations establish a security baseline for audit logging, network isolation, and backup requirements, enabling consistent security configuration monitoring across database estates.
