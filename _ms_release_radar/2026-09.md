## Security Architect Observations

- AKS lifecycle changes (VMAS auto‑migration, Azure Linux with OS Guard retirement, Windows Server 2022 and Flatcar removal) require coordinated node pool, OS image, and upgrade planning across clusters.
- The Defender for Servers billing policy and billable server identification changes may alter protected‑server counts; validate licensing, coverage, and cost in Plans 1 and 2 before November 1, 2026.
- Entra's move toward workload identity and token binding (mTLS PoP, SAP SuccessFactors workload identity) reduces long‑lived credential risk; plan Conditional Access token‑protection cohorts and preproduction validation.
- The transition from grouped to individual vulnerability assessment recommendations (December 14, 2026) affects governance, reporting, and ownership workflows across subscriptions.
- Sentinel data lake plus Microsoft Fabric mirroring/federation changes the data architecture; review data residency, governance, and cross‑tenant access before adopting.
- Azure Functions runtime retirements (PowerShell 7.4, .NET 8/9) require platform modernization and, for Linux Consumption apps, migration to Flex Consumption.

## Security Operations Observations

- Sentinel data lake adoption changes SOC workflows: interactive KQL in Advanced Hunting, Fabric notebooks/pipelines, and graph analytics require new hunting and retention procedures.
- MDE expansion to WSL containers and Linux desktops broadens endpoint coverage; tune device inventory, alerting, and scoping to avoid noise from newly covered workloads.
- MDVM's expanded Linux visibility into Node.js, Python, and Java libraries will likely surface new vulnerability findings; expect higher triage volume.
- Defender for Identity automatic sensor v3.x activation and Windows auditing may shift sensor topology and event collection; confirm coverage and alert tuning after rollout.
- AKS component updates (Istio, Gatekeeper, Cilium, Gateway API) can change policy enforcement and network telemetry; validate detection rules and monitoring after upgrades.
- Defender Container Sensor updates (v0.8.x–v0.11.x) include security vulnerability and dependency fixes; verify deployed sensor versions and track the change log.
