# Microsoft Security Release Radar - September 2026

## ⛵ AKS

| Indicator | Feature | Type | Description |
|---|---|---|---|
| ⚫ | Automatic migration of deprecated Availability Sets (VMAS) clusters | Deprecation | Starting September 30, 2026, AKS will auto-migrate deprecated VMAS clusters to Virtual Machines node pools via the auto-upgrader. Migrate before that date using `az aks update --migrate-vmas-to-vms` to control timing. |
| ⚫ | Retirement of Azure Linux with OS Guard (preview) | Deprecation | Azure Linux with OS Guard for AKS (preview) retires December 10, 2026; transition to Azure Container Linux by that date. After retirement, no new node images or security patches are produced, and node images are removed March 10, 2027. |
| 🟢 | Autoscaling for Virtual Machines node pools | GA | Autoscaling for Virtual Machines node pools, including multi-SKU autoscaling, is now generally available. |
| 🟡 | Convert existing clusters to a managed system node pool | Preview | Existing clusters can now be converted to use a managed system node pool in supported regions after registering the required preview feature. |
| 🟡 | Blue-green to rolling upgrade switch | Preview | Node pools with an in-progress blue-green upgrade can now switch safely to the rolling upgrade strategy. |
| 🟡 | On-Demand Monitor (Cluster Health Monitor) | Preview | A new Cluster Health Monitor capability for node health checks and remediation is available in preview. |
| 🔵 | Kubernetes 1.37 preview and patch versions | New/Updated | Kubernetes 1.37 Preview is rolling out; patch versions 1.36.3, 1.35.7, and 1.34.10 are now available. |
| 🔵 | LocalDNS auto-enablement from Kubernetes 1.37 | New/Updated | Starting with Kubernetes 1.37, LocalDNS is enabled automatically when cluster networking supports it; BYO-CNI, unsupported network policies, and custom DNS configs are unchanged. |
| 🔵 | IPv6 removal from dual-stack clusters rejected | New/Updated | AKS now rejects updates that attempt to remove IPv6 from an existing dual-stack cluster; dual-stack to single-stack migration isn't supported. |
| 🔵 | HTTP proxy / custom CA size limit | New/Updated | New clusters using an HTTP proxy or Custom Certificate Authority now reject CA certificate content larger than 35 KB to prevent node bootstrap data from exceeding platform limits. |
| 🔵 | Reserved namespace prefix protection | New/Updated | Managed namespace creation now rejects names beginning with `kube-` or `aks-istio-` to prevent conflicts with system-reserved namespaces. |
| 🔵 | Azure Policy Kubernetes-native validation default | New/Updated | When the Azure Policy add-on is enabled, Azure Policy's Kubernetes-native validation path is now enabled by default across regions. |
| 🔵 | Static Egress Gateway deregistration | New/Updated | Static Egress Gateway nodes now deregister from the load balancer before node-image upgrade reimaging, reducing risk of interrupted egress traffic. |
| 🔵 | KMS encryption-at-rest validation | New/Updated | AKS returns a validation error when enabling KMS encryption-at-rest on 1.37 clusters with versioned Key Vault key IDs; versionless key IDs are required. |
| 🔵 | Defender for Containers collector CSI detach fix | New/Updated | Fixed an issue where the Defender for Containers collector could prevent CSI volumes from detaching, blocking dependent pods from scheduling. |
| 🔵 | Windows node metrics fix | New/Updated | Fixed missing Windows node metrics caused by an incorrect exporter port configuration. |
| 🔴 | Istio service mesh security patches (ISTIO-SECURITY-2026-006) | Security | Istio-based service mesh add-on revisions updated with security patches for ISTIO-SECURITY-2026-006: asm-1-29 to v1.29.7 and asm-1-30 to v1.30.4. Restart workload pods to reinject the updated istio-proxy sidecar. |
| 🔵 | Gatekeeper v3.23.1 | New/Updated | Gatekeeper updated to v3.23.1, fixing excessive Validating Admission Policy reconciliation requests. |
| 🔵 | Managed Gateway API v1.6.1 | New/Updated | Managed Gateway API on Kubernetes 1.37 now uses the Gateway API v1.6.1 standard-channel CRD bundle, adding graduated TCPRoute and UDPRoute resources. |
| 🔵 | Azure CSI driver updates | New/Updated | Azure File, Disk, and Blob CSI drivers updated across AKS 1.33–1.35+ versions. |
| 🔵 | Cloud Provider Azure component updates | New/Updated | Cloud Provider Azure components updated to v1.33.17-2 and v1.36.5-2, including cloud-controller-manager, cloud-node-manager, and health-probe-proxy. |
| 🔵 | Cilium / Hubble Relay / ACNS FQDN image updates | New/Updated | Cilium, Hubble Relay, and Advanced Container Networking Services FQDN policy images updated across Kubernetes 1.31–1.36. |
| 🔵 | App Routing 0.2.28 | New/Updated | App Routing updated to 0.2.28 with ingress-nginx bumped to v1.13.10-10 and additional validation for custom log formats. |
| 🔵 | Node image updates | New/Updated | Windows Server 2022/2025, Azure Linux v3.0, Azure Container Linux, and Ubuntu 22.04/24.04 node images updated. |
| ⚫ | AppNet 1.0/1.1/1.2 retirement | Deprecation | AppNet versions 1.0 (Istio 1.25), 1.1 (Istio 1.26), and 1.2 (Istio 1.27) are retired; self-managed upgrade mode users should upgrade to a supported version. |
| 🟡 | AppNet public preview in additional regions | Preview | AppNet is now available in public preview in additional regions including Central US, East US, Japan East, North Europe, South India, Southeast Asia, and West US regions. |
| 🔵 | AppNet bug fixes | New/Updated | AppNet fixes include cluster prerequisite validation at member-join, Gateway API CRD ownership conflict resolution, reliable certificate rotation, east-west gateway network labels, and orphaned resource cleanup. |
| 🔵 | AppNet component updates | New/Updated | AppNet 1.3 updated to Istio 1.28.10, AppNet 1.4 to Istio 1.29.6, and AppNet 1.5 (Istio 1.30) is now available using Istio 1.30.3. |

## Security Architect Observations

- **Service mesh security posture:** The ISTIO-SECURITY-2026-006 patches across AKS Istio add-on revisions (asm-1-29, asm-1-30) and AppNet (Istio 1.28.10/1.29.6/1.30.3) require coordinated pod restarts to reinject sidecars; plan maintenance windows and validate mesh health after rollout.
- **Deprecation-driven migration:** VMAS auto-migration and Azure Linux with OS Guard retirement create forced migration timelines; architect node pool and OS migration plans now to avoid unplanned auto-upgrade behavior and scaling/remediation failures after March 2027.
- **Multicloud coverage expansion:** Over 200 new GA multicloud recommendations now affect Secure Score across ~90 AWS/GCP resource types; reassess multicloud posture baselines and remediation ownership across cloud teams.
- **SQL VA transition:** The shift from grouped to individual SQL VA recommendations changes how findings are consumed via API and portal; update automation and reporting that depends on grouped sub-assessment data.
- **Container security hardening:** New serverless container recommendations (least privilege, public exposure, authentication) for ECS Fargate, Azure Container Apps, and Container Instances should be folded into CI/CD and IaC guardrails.

## Security Operations Observations

- **New detections to tune:** The "abnormally large number of rows extracted from your SQL server" preview alert and new EMR/Neptune/MSK/OpenSearch recommendations add SOC coverage; baseline normal behavior to reduce false positives.
- **Secret protection at PR layer:** The new ruleset to block PRs with exposed secrets complements push protection; configure secret types and monitor bypass permissions to avoid merge friction.
- **Defender for Identity sensor expansion:** Sensor v3.x now covers AD CS, AD FS, and Entra Connect servers; onboard these identity infrastructure roles and review the new combined Sensor management tab for activation status.
- **Endpoint memory scanning:** Linux memory scanning (preview) adds in-memory threat visibility; validate performance on production Linux hosts and consider enabling via Insiders-slow channel first.
- **WSL container visibility:** MDE plug-in for WSL containers (WSLc) extends detection to Linux workloads; enroll and incorporate WSL container alerts into Advanced Hunting workflows.
- **Recommendation retirement monitoring:** Legacy grouped recommendation retirement removes API access to deprecated data; verify dashboards and SOAR playbooks that query sub-assessment data are migrated to individual recommendations.
